# Logistics Data Analysis Strategic Planning

This Week 1 project proposes a data analysis plan for an online retailer that wants to improve demand planning and local deliveries.

## Objectives

- Forecast daily order demand.
- Measure on time deliveries, forecast error, delivery distance, and vehicle utilization.
- Explore how delivery routes could be planned around vehicle capacity and customer time windows.

## Data

The report uses the UCI Online Retail II dataset as a proposed source for transaction analysis. Delivery times, vehicle details, and routes would require additional company data. No delivery results have been measured yet.

## Methods

The plan covers data cleaning and exploration with Python, a baseline demand forecast, regression, possible geographic clustering, and route optimization using OR Tools.
